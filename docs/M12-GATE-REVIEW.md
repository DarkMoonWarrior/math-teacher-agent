## 固定评测入口

从仓库根目录、安装本项目 API 开发依赖的 Python 环境执行：

```powershell
python -m pytest -c apps/api/pytest-m12.ini -q
python -m pytest apps/api/tests -q
pnpm test:teacher
pnpm typecheck:teacher
pnpm build:teacher
pnpm test:agent
pnpm typecheck:agent
pnpm build:agent
pnpm check:repo
```

`pytest-m12.ini` 固定列出 17 个测试文件，而非动态通配符。前 9 个覆盖 M12 身份、运维、备份、生命周期、任务/模型会话、路由和缓存边界；后 8 个重跑 Search 到 Teacher Memory 的既有固定合成质量评测。数据只在临时测试目录；Runtime/OCR/模型使用测试替身，没有使用真实凭据、私人资料或第三方试题。

当前固定入口结果为 **138 passed、1 skipped**（139 个 pytest 用例，包括内部包含多个合成场景的既有评测）。这不是 139 次真实教师任务，也不意味着全部 M12 产品边界已经完成。配置使用显式文件参数，路径错误会失败，不静默退回扫描全仓库。
