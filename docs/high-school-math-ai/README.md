# high-school-math-ai 历史地基

本目录来自旧 `high-school-math-ai` 原型，保留当前教材加载所依赖的目录，以及业务架构、数据审计、权利声明与研究证据。旧 UI 信息架构已移除。

归档状态（2026-09-04）：旧 UI 源码已从当前仓库移除。历史文件中的旧路径、阶段状态与分支名仅代表当时记录；当前实现以 [项目状态](../PROJECT-STATUS.md) 为准。

使用方式：

- 复用其中经过测试的业务知识、数据 schema、教材与治理证据；
- 通过当前 FastAPI 模块和稳定 interface 渐进接入新产品；
- 不照搬旧 UI，不把旧路线图当作当前开发顺序；
- 不把历史审计或私人数据声明自动视为商业授权。

当前边界、架构和路线图位于上一级目录的 `DEVELOPMENT-BOUNDARY.md`、`ARCHITECTURE.md`、`PROJECT-STATUS.md` 与 `ROADMAP.md`。
