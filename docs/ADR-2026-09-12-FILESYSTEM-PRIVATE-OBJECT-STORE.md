# ADR：本地私有对象字节存储 Adapter

- 状态：已接受（M14 工程切片）
- 日期：2026-09-12
- 范围：`PrivateObjectNamespace` 后的本地字节持久化、读取与受控删除

## 背景

私有对象命名空间已经固定 tenant/owner 授权、对象键和保留策略，但尚未证明字节写入在重试、冲突、内容损坏和文件系统边界下能安全工作。现有各业务模块直接管理目录，不能直接当作未来云对象存储契约。

当前仓库的真实开发运行方式仍是单机本地文件系统，因此先实现这一种实际 Adapter；没有第二种真实部署时不提前增加空泛的云存储抽象。

## 决策

新增 `FilesystemPrivateObjectStore`，它只接受已经由 `PrivateObjectNamespace` 绑定的对象。调用顺序固定为：

1. 当前正式会话提供服务端 `PrivateObjectScope`；
2. namespace 重新授权 binding 与逻辑对象 ID；
3. Adapter 才能检查根目录和执行字节 IO。

因此跨 owner/tenant 请求会在检查对象是否存在之前失败，存储层不会成为对象枚举旁路。

### 根目录边界

- 构造时必须明确确认这是私有存储根；调用 `prepare()` 后写入专用 marker。
- 未标记且非空的目录不能被 Adapter 接管；marker 缺失、被修改、变成链接或根目录出现链接/reparse 都失败关闭。
- 对象路径只能由 namespace 返回的规范 storage key 分段得到。Adapter 不接受浏览器、Agent、模型或业务路由提供的任意相对/绝对路径。

### 原子与幂等语义

- 单对象上限固定为 128 MiB，覆盖当前 100 MiB 的单 PDF 上限；调用方不能通过路径或 header 放大这一限制。
- 内容先写入同目录随机 pending 文件并 `fsync`，再以同文件系统原子 hard-link 发布；发布永不覆盖已有目标。
- 相同键与相同字节的重试返回 `already-present`；相同键出现不同字节返回 `PRIVATE_OBJECT_CONTENT_CONFLICT`，保留原内容。
- 进程若在发布与 pending 清理之间中断，会留下多硬链接歧义；后续读取失败关闭，不猜测哪一个名称可信。专门的维护/恢复流程后续实现。

### 完整性与删除

- 每个文件是单一 envelope，头部固定保存 schema、字节长度和 SHA-256，正文与元数据一并原子发布。
- 读取逐项验证文件类型、单链接、envelope schema、长度和校验和；损坏只返回稳定错误，不返回部分正文。
- 删除必须再次通过当前作用域授权，并提交预期 SHA-256；内容变化时拒绝删除。目标已不存在时幂等返回 `deleted=false`。
- receipt 的对象表示隐藏内容校验和，binding 的对象表示隐藏 storage key。

## 限制

- 这是开发/单机文件系统 Adapter，不是云对象存储、共享网络文件系统或生产高可用声明。
- 当前 API 仍以整块 `bytes` 读写，尚未提供大对象流式上传/下载、分片恢复、跨进程锁、配额、病毒扫描、加密密钥管理或生命周期任务。
- 现有资料、题图、PDF、试卷/教案版本和导出尚未接入本 Adapter；没有复制、删除或迁移真实用户文件。
- 根目录需要支持同文件系统 hard-link；未来 S3 兼容 Adapter 必须实现自己的条件写、校验和、版本与恢复语义，不能照搬本地文件操作。

因此本切片只证明本地字节 Adapter 的安全语义，不代表生产对象存储或持久任务已完成。
