- 已完成：教师显式保存、精确题目 revision 与可信事实复核、草稿指纹冲突保护、owner-scoped append-only 不可变版本。
- 已完成：教师明确选题后，知识范围和难度由服务器自动归纳并进入双向细目表；题量、题型/分区、配分、总分或分析偏差均只作可见提示。保存前提供取消/确认，教师确认后保存当前精确版本；无题或题目可信/完整性失败仍拒绝。
- 已完成：从当前 owner 的精确已保存版本导出学生卷、答案卷和双向细目表 DOCX/PDF；学生卷不含答案，答案卷含可读解析。
- 部分完成：本地 current-teacher adapter 只用于开发，不代表生产认证、云 tenant isolation、备份恢复或商业公共题库已经就绪；当前本地合格公共题供给为 0。

- 超范围修改：无；没有新增依赖、填充商业题库、自动命题补缺或放宽私题可见性。

## 3. Gate E

1. 范围：已完成、部分、未开始与超范围项已在上节列明。
2. 工程回归：FastAPI `406 passed`（仅 1 条 Starlette TestClient 依赖弃用提示）；Teacher Web 13 个测试文件、68 项测试、类型检查和生产构建通过；Agent 10 个测试文件、42 项测试、类型检查和生产构建通过；legacy Web 类型检查和生产构建通过。
3. 故障体验：大学范围、权利/验证/审核拒绝、供给不足、跨 owner、伪造布局、陈旧指纹和未知版本均 fail closed；缺题保持可编辑真实缺口，不自动命题、不隐式保存，也不把内部异常字段展示为成功结果。
4. 可信边界：Agent 只经 allowlisted Tool，无 SQL/SQLite/PostgreSQL/ORM 直连，也没有组卷写入、保存、导出、发布或删除 Tool；MathVerifier、教师审核和 RightsGate 不可由浏览器覆盖。
5. 仓库卫生：未跟踪数据库、上传、导出、私有运行数据或真实私人内容；仅保留无密钥的 `.env.example`；`data/commercial-approved` 仍只有说明文件。
6. 依赖/迁移/删除：无新依赖、无破坏性迁移、无扩大删除语义；版本保存为 append-only，导出没有业务写入。
7. owner 权限：浏览器 owner/可信字段伪造、跨 owner 私题读取、跨 owner 已保存版本导出和精确版本访问均有自动化测试并 fail closed。

## 4. Gate P 连续性

- `PersonalQuestionLibrary` 与公共 `QuestionBank` 继续保持业务接口和存储命名空间分离；组卷只保存私题的不可变引用快照，不复制私题、不改变 owner/visibility。
- 私题只有当前 owner 明确勾选时才可进入候选；后台、公共 Search、其他 owner 和 Agent 均不能浏览或自动采用。
- 公共候选必须通过 public/active、教师审核、MathVerifier 和权利门禁；本地无合格供给时诚实显示空状态。
- 浏览器只提交蓝图、明确题目 ID、布局编辑和草稿指纹；owner、可信、权利、revision 与版本事实由服务端决定。
- 固定评测与工程测试均只使用 synthetic 内容，没有把测试题写入公共、私人或商业批准数据。
