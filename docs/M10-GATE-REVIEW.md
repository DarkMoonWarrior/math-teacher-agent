# M10 Lesson Agent Gate 评审

评审日期：2026-08-31

结论：**M10 六条纵向切片、固定评测、功能 Gate、Gate E 与 Gate P 连续性检查已通过；当前工作树达到项目所有者验收条件。M11 仍需等待这批变更形成可回滚提交并由项目所有者明确确认，不得提前启动。**

## 1. 范围核对

- 已完成：自然语言课堂要求到可编辑蓝图、可见默认假设、封存教材基线和高中范围门禁。
- 已完成：教师确认后明确选择受控公共题、本人私题和本人私人资料；服务端重新解析 owner、权利、可信状态和精确 revision；真实缺口不由 Agent 编造内容掩盖。
- 已完成：闭环完整教案正文，包含目标与证据、重难点、课堂流程、完整题目事实、评价、作业、板书、备注和来源清单；课时及目标—活动—评价对应由服务端检查。
- 已完成：逐块本地编辑、锁定和定向重写；题干、选项、答案、解析及非目标块不可借改写漂移。
- 已完成：教师显式保存、当前 owner 历史、历史编辑另存新版本、回收/恢复和 append-only 不可变快照；保存不升级 `draft_requires_teacher_review`。
- 已完成：从当前 owner 指定已保存版本导出完整教师教案 DOCX/PDF；页面临时状态和后续版本不会串入旧版本。
- 部分完成：本地 current-teacher adapter 不代表生产认证、云 tenant isolation、备份恢复或真实教师 Beta 已完成。
- 未开始：M11 Memory、Closed Beta、支付、多租户、教研组和学校能力。
- 超范围修改：无；没有新增公开/共享/发布路径，没有让 Agent 保存或导出，也没有降低高中、权利、可信或 owner 门禁。

## 2. 固定评测

[`M10-LESSON-AGENT-EVALUATION.md`](M10-LESSON-AGENT-EVALUATION.md) 记录 28 个项目自建 synthetic 场景。蓝图、范围、来源、owner/IDOR、完整教案、题目事实、目标对应、逐块编辑、版本、导出和 Agent 权限共 15 类违规全部为 0。

## 3. Gate E

1. 范围：已完成、部分完成、未开始与超范围项已在上节列明。
2. 工程回归：FastAPI `435 passed`（仅 1 条既有 Starlette TestClient 依赖弃用提示）；Teacher Web 16 个测试文件、82 项测试、类型检查和生产构建通过；Agent 10 个测试文件、42 项测试、类型检查和生产构建通过；legacy Web 类型检查和生产构建通过。
3. 故障体验：大学范围、来源缺口、来源 revision 漂移、题目事实篡改、锁定块、跨 owner、未知版本和导出失败均 fail closed；正常完成不返回半份教案。
4. 可信边界：Agent 只经 allowlisted Tool，无数据库直连，也没有教案保存、导出、生命周期、发布或共享 Tool；浏览器不能覆盖 owner、权利、可信或 revision。
5. 仓库卫生：评测只使用 synthetic 内容；真实私人资料、运行数据库、导出物和 QA 图片不作为产品数据提交。
6. 依赖/迁移/删除：无新依赖、无破坏性迁移；M10 新版本 append-only，删除入口为可恢复回收站，导出不修改业务状态。
7. owner 权限：浏览器 owner 伪造、跨 owner 历史/读取/生命周期/导出均在业务层拒绝，不依赖 UI 隐藏。

## 4. Gate P 连续性

- 私题和私人资料仍经独立业务 Module 读取，只有当前 owner 明确选择时才进入教案来源；引用不改变 owner、visibility 或可信状态。
- 公共题仍必须通过 public/active、教师审核、数学验证、权利和高中范围门禁。
- 教案版本 private-by-default；没有 public/shared/team/school/commercial-approved 状态迁移。
- Agent、其他教师和后台均没有通过 M10 Interface 读取或管理另一 owner 教案正文的能力。
- 固定评测没有把 synthetic 教案、题目或资料写入公共、私人或商业批准题库。

## 5. 界面与导出验证

- Teacher Web 保持可拖动左右布局；蓝图、来源、完整正文、逐块编辑、明确保存、本人历史、回收/恢复和已保存版本导出在一个工作流中闭环。
- 16 个教师端测试文件覆盖工作区布局、接口适配、历史/保存/导出状态和已有响应式行为；类型检查及生产构建通过。
- 精确版本 DOCX 5 页、PDF 4 页逐页视觉检查通过；题面、选项、答案、解析、课堂关系和来源摘要完整，无裁切、重叠、乱码或后续版本串入。

## 6. 阶段转换

M10 工作树已达到功能与工程验收条件，但本评审不自动授权 M11。先形成可回滚提交，再由项目所有者查看结果并明确确认阶段转换；此前只允许修复 M10 blocker，不开始 Teacher Memory。
