## M12 完成内容

1. `BetaAccess`：opaque HttpOnly 会话、哈希存储、到期/撤销、服务端 owner 和不可变能力快照。
2. `PrivacySafeOperations` / `ReadinessProbe`：allow-list 运行事件与不泄露私密配置的稳定就绪状态。
3. 任务、模型会话、全部路由入口及资料/图片/候选/后台任务/试卷/教案对象的 current-owner 隔离。
4. `BetaBackupRecovery`：明确私有目的地、SQLite 在线快照、原子发布、精确校验和隔离恢复；路径、链接、junction/reparse 失败关闭。
5. 数据生命周期：owner 固定确认删除私题、资料、图片、试卷、教案；独立快照保留；当前墓碑阻止旧备份复活；备份 30 天、失效会话预览/确认清理、导出响应后删除和终态任务 24 小时保留。
6. Closed Beta 和正式账号模式均停用缺少安全 owner 契约的旧导入、题库管理/媒体、相似度/解题、旧教案、旧组卷写入和全局模型管理入口；纯本地开发保持兼容。
7. `/api/v1` 及 Search/Solve 流式代理统一 `private, no-store`。

## M13 延期状态

`BetaValidationMetrics` 已把 16 项 Gate 指标和教师权利收口在一个深模块 Interface 中：严格枚举事件、HMAC 摘要 owner/task、按可信等级分层严重数学错误、零分母返回空值，并计算选择/导出/保存转化、留存、Tool 失败、成本与耗时。采集开关默认关闭；教师确认 `m13.notice.v1` 后才允许记录，事件保留 90 天，本人可以导出聚合或退出并删除本人事件。`BetaValidationFacts` 进一步隐藏采集状态、参与状态、事件映射和存储故障；Search/Solve、命题、Paper、Lesson、资料导入及私题保存已从服务端成功节点接入，主事件与完成/Tool 结果原子写入且任何指标故障不影响教师工作流。Search 只有点击真实结果才形成选择，搜索/解题评价要求 current-owner 的已完成 run 且最后一次决定生效。模型成本只接受 FastAPI 直接持有可信 owner 的调用，并按显式配置的 OpenAI/DeepSeek 费率快照计算；隔离 Agent 内部调用在建立签名 owner 传递前保持不归因。默认配置仍不会采集。

切片 4 增加了仅本机操作者可运行的只读聚合命令。它展示统计窗口、事件数、确认参与数、激活教师数、所有指标的分子/分母、可信等级错误率，以及按周聚合的 Week-1/Week-4 cohort 进度；同时明确标注样本是否达到 20–30 位目标。该命令没有 HTTP、浏览器或 Agent 入口，不输出逐人/逐任务信息，不读取正文，也不会在指标库缺失时创建空库。当前默认配置仍关闭采集且没有真实指标库，因此只读预演会安全返回“未就绪”，不能据此宣称已有 Beta 样本。

切片 5 增加一次性操作预演：七条安全检查只在自动删除的合成临时库中执行，覆盖告知、本人导出、运营读数、保留清理与退出删除；当前部署只做不含路径/密钥的只读 preflight。实际预演七项均通过，Beta 访问已开启，但本地部署仍明确报告 `COLLECTION_DISABLED`、`IDENTITY_SECRET_MISSING` 和 `METRIC_STORE_MISSING`，因此当前不具备邀请真实教师参与指标验证的技术配置条件，也没有产生任何真实指标。

## M14 当前进度

第一条切片建立了 `AccountIdentity` 深模块 Interface，并明确拆分 `account_id`、`tenant_id` 与现有私人内容使用的 `owner_id`。正式会话只把服务端解析出的 owner 注入业务模块，浏览器、Agent、模型及请求参数不能选择身份。内存与 SQLite 两个 adapter 证明 Interface 可替换；密码使用 scrypt，会话 token 只存摘要且可到期/撤销。公开 HTTP 只有登录、状态和退出，没有自助注册或 Agent 创建账号入口。正式身份、封闭测试与纯本地开发三种模式互斥；错误配置同时开启前两者时 fail closed。`/ready` 只检查当前模式需要的身份存储，本地模式不创建无用会话库，冲突模式明确降级。能力定义已上移到全局工作台边界，旧版单用户接口在任一账号模式均停用。

第二条切片的第一段增加了独立 `AccountAdministration` 操作者边界。本机命令可显式确认创建、停用账号和重置密码；停用或重置会原子撤销该账号全部旧会话，交互式密码不会出现在参数或回执中。正式会话清理默认只读预览，确认后只删除已过期或已退出记录；有效会话、异常记录和教师内容均保留。维护工具先只读验证配置库与精确 schema，不接受任意路径，也没有 HTTP、浏览器或 Agent 入口。

第二条切片的第二段增加了独立 `AccountLoginProtection` 边界。正式登录在应用层同时限制账号摘要与连接来源摘要，默认 15 分钟内分别允许 5 次与 30 次失败；安全事件只保存 HMAC 摘要、结果和时间，默认保留 168 小时，不保存邮箱、IP、密码、token 或请求正文。成功登录清零该账号此前失败窗口并轮换当前浏览器旧会话；登录防护密钥不足、存储不可用或安全事实无法写入时失败关闭。应用只使用实际连接来源，不信任浏览器可伪造的转发头；生产代理信任与分布式限流仍是部署前置工作。MFA 当前没有假装实现，个人商业账号、未来组织特权角色、恢复码与 step-up 路线已固定在登录安全 ADR 中。

正式身份功能仍默认关闭，SQLite 仅是过渡 adapter，尚未创建真实账号或迁移真实内容。账号找回、MFA 实现、完整操作者审计、密钥轮换、可信生产代理与分布式限流、PostgreSQL tenant adapter、对象存储、持久任务、Entitlement、订单、支付与退款仍未实现；详见 [`M14-COMMERCIAL-FOUNDATION.md`](M14-COMMERCIAL-FOUNDATION.md)。
