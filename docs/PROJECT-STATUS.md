## M12 完成内容

1. `BetaAccess`：opaque HttpOnly 会话、哈希存储、到期/撤销、服务端 owner 和不可变能力快照。
2. `PrivacySafeOperations` / `ReadinessProbe`：allow-list 运行事件与不泄露私密配置的稳定就绪状态。
3. 任务、模型会话、全部路由入口及资料/图片/候选/后台任务/试卷/教案对象的 current-owner 隔离。
4. `BetaBackupRecovery`：明确私有目的地、SQLite 在线快照、原子发布、精确校验和隔离恢复；路径、链接、junction/reparse 失败关闭。
5. 数据生命周期：owner 固定确认删除私题、资料、图片、试卷、教案；独立快照保留；当前墓碑阻止旧备份复活；备份 30 天、失效会话预览/确认清理、导出响应后删除和终态任务 24 小时保留。
6. Closed Beta 中停用缺少安全 owner 契约的旧导入、题库管理/媒体、相似度/解题、旧教案、旧组卷写入和全局模型管理入口；当前工作台与本地开发兼容。
7. `/api/v1` 及 Search/Solve 流式代理统一 `private, no-store`。

## 工程基线与限制

M13 当前固定集 **205 passed、1 skipped**；完整 FastAPI **654 passed、1 skipped**。M12 收口时 Teacher Web **102 passed**、Agent **42 passed**，双方类型检查和生产构建通过；本切片没有修改两个前端。自动测试只使用临时目录、合成内容和 provider 替身，不调用真实模型或清理真实用户数据。

`apps/teacher-web` 是唯一产品 UI；旧 UI 源码、入口和依赖已移除。运行库、私人上传、环境、导出与备份不进入 Git。商业题目目录仍为空，合成 fixture 不具备第三方内容权利。

生产认证/RBAC/MFA、多租户、组织/学生、支付、云对象存储、自动备份调度、生产灾备和真实 Beta 指标尚未完成。M13 已经项目所有者确认启动，但当前只建立 `m13.v1` 合成指标契约；尚未启用真实采集，也不能用 M12/M13 合成测试代替 20–30 位真实教师验证。

`BetaValidationMetrics.record/snapshot` 已把 16 项 Gate 指标收口在一个深模块 Interface 中：严格枚举事件、HMAC 摘要 owner/task、按可信等级分层严重数学错误、零分母返回空值，并计算选择/导出/保存转化、留存、Tool 失败、成本与耗时。模块尚未接入 FastAPI 全局依赖、公开路由、Teacher Web 或真实工作流，因此当前不会采集真实教师行为。下一切片先固定保留期、教师告知、导出和删除规则，再决定启用方式。
