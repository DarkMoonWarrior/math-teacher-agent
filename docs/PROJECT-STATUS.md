## M12 完成内容

1. `BetaAccess`：opaque HttpOnly 会话、哈希存储、到期/撤销、服务端 owner 和不可变能力快照。
2. `PrivacySafeOperations` / `ReadinessProbe`：allow-list 运行事件与不泄露私密配置的稳定就绪状态。
3. 任务、模型会话、全部路由入口及资料/图片/候选/后台任务/试卷/教案对象的 current-owner 隔离。
4. `BetaBackupRecovery`：明确私有目的地、SQLite 在线快照、原子发布、精确校验和隔离恢复；路径、链接、junction/reparse 失败关闭。
5. 数据生命周期：owner 固定确认删除私题、资料、图片、试卷、教案；独立快照保留；当前墓碑阻止旧备份复活；备份 30 天、失效会话预览/确认清理、导出响应后删除和终态任务 24 小时保留。
6. Closed Beta 中停用缺少安全 owner 契约的旧导入、题库管理/媒体、相似度/解题、旧教案、旧组卷写入和全局模型管理入口；当前工作台与本地开发兼容。
7. `/api/v1` 及 Search/Solve 流式代理统一 `private, no-store`。

## M13 当前进度

`BetaValidationMetrics` 已把 16 项 Gate 指标和教师权利收口在一个深模块 Interface 中：严格枚举事件、HMAC 摘要 owner/task、按可信等级分层严重数学错误、零分母返回空值，并计算选择/导出/保存转化、留存、Tool 失败、成本与耗时。采集开关默认关闭；教师确认 `m13.notice.v1` 后才允许记录，事件保留 90 天，本人可以导出聚合或退出并删除本人事件。`BetaValidationFacts` 进一步隐藏采集状态、参与状态、事件映射和存储故障；Search/Solve、命题、Paper、Lesson、资料导入及私题保存已从服务端成功节点接入，主事件与完成/Tool 结果原子写入且任何指标故障不影响教师工作流。Search 只有点击真实结果才形成选择，搜索/解题评价要求 current-owner 的已完成 run 且最后一次决定生效。模型成本只接受 FastAPI 直接持有可信 owner 的调用，并按显式配置的 OpenAI/DeepSeek 费率快照计算；隔离 Agent 内部调用在建立签名 owner 传递前保持不归因。默认配置仍不会采集。
