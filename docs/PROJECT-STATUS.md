## M12 已完成切片

1. `BetaAccess.issue/resolve/revoke`：私有访问名单、opaque HttpOnly 会话、哈希存储、到期/撤销；开启后无有效会话 fail closed。仅禁用 Beta 的本地开发可使用固定教师。
2. 服务端能力快照：七类 allow-list 能力在签发时冻结；未开放能力在业务路由前返回 403，前端不挂载对应工作区。名单变更不提升已签发会话权限。
3. `PrivacySafeOperations` / `ReadinessProbe`：只记录请求编号、能力、结果、稳定错误类别与耗时；`/ready` 返回稳定组件状态，不暴露正文、身份、密钥、URL 或原始异常。
4. `BetaBackupRecovery`：固定持久化 store 清单、SQLite 在线快照、明确私有目的地、清单/逐文件校验、隔离临时恢复演练；不覆盖在线数据，不备份可撤销会话，无浏览器/Agent 入口。

切片 5 已补充真实会话/临时数据测试，封闭测试停用旧导入、旧题库管理/查重/解题、旧教案 REST 及全局模型管理入口；当前工作台使用的新接口不受此限制。本人偏好/私题永久删除和资料回收边界经过演练。经所有者确认，新增默认预览、明确确认后才删除到期/退出登录记录的独立维护命令；有效会话、教师内容和备份不受影响，没有清理真实记录。API 和搜题/解题流式代理补充禁止缓存响应头。详见 [数据生命周期记录](M12-DATA-LIFECYCLE.md)。尚未新增全账户清除、备份清除或其他存储的永久删除能力。

随后修复 Search/Solve 任务记录缺少 owner 校验和四类 Agent 入口直接复用浏览器会话编号的问题；运行上下文现按教师和模块隔离。旧组卷 create/compose/compose-template/update 在 Beta 中停用，新版蓝图和历史管理不变。备份拒绝原始路径/父目录链接及 Windows reparse，存储标识不能逃出 payload。全路由入口拒绝回归覆盖匿名、到期、退出重放和空能力四种状态。固定评测及完整 Gate 的待办见 [M12 Gate 记录](M12-GATE-REVIEW.md)。当前仅支持单 API 进程；服务重启后旧模型会话不可重用，已保存内容不变。
