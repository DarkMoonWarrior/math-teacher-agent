# M12 数据生命周期与删除演练

核对日期：2026-09-05。切片 5 **部分完成**，不是完整隐私审计、账户注销或 M12 完成声明。

## 本轮决策与修复

所有者确认：允许在封闭测试模式下停用不安全旧接口；本地开发入口和已有数据保持不变。

复现使用临时目录中的自建空白 PDF、两个独立访问码签发的真实会话，不覆盖 `get_current_teacher`。修复前，用户 B 对 A 的旧导入批次执行列表、原文件下载和移入回收站均返回 200。原因是旧路由仅检查模块开放能力，未把当前用户传入业务查询；旧存储操作也没有按 owner 筛选。会话本身没有串用。

`require_local_legacy_access` 在 Beta 开启时返回稳定的 403 / `LEGACY_WORKFLOW_UNAVAILABLE`，且在业务存储和模型依赖运行前拒绝请求。限制范围：

- 旧 `/imports` 整组接口。
- 旧 `/questions`、`/question-bank` 题库管理接口（包括旧题图下载）。
- 旧 `/question-similarity` 与 `/solutions` 接口。
- 旧教案列表、即时生成、详情、编辑、锁定、重写、导出和生命周期接口。
- 旧 `/admin/model-operations` 全局模型管理入口；Beta 中先拒绝再访问全局存储，内部运行记录不因路由关闭而停用。
- 旧组卷 `POST /exam-papers`、`POST /exam-papers/compose`、`POST /exam-papers/compose-template`、`PUT /exam-papers/{paper_id}`；旧 composer 没有 owner 参数且默认查询全局题库，合成私有题摘要复现返回 200 后补齐 Beta 禁用。新版蓝图、历史读取、history-revision、回收和精确版本导出不受影响。

当前 `/library`、`/search-agent`、`/solve-agent`、私题库、组卷、教案 `blueprints` / `versions` 接口不因这一限制关闭。内部业务函数和受控 Tool 不受路由限制影响。当前 Teacher Web 适配器不调用被停用的旧 REST 流程；如有外部旧客户端，须迁移，不能通过关闭 Beta 开关规避身份隔离。

旧接口限制没有修改数据库结构或内容删除语义，也没有清理真实用户文件。此处的模式开关不是角色系统，更不能替代现有产品接口中的 owner 校验。后续独立的会话维护已获得所有者明确批准，范围见下文。

## 持久化覆盖与实际保留行为

与 `owner_store_sources` 中的备份范围逐项对应。下表描述现状，**不是承诺的保留期限**。

| 存储标识 | 当前访问/导出能力 | 当前删除与残留边界 |
| --- | --- | --- |
| `personal_question_library` | 本人私题 JSON / Markdown 导出、命题历史 | 永久删除需先回收、当前版本和固定确认；清除该题活动记录及来源草稿/修订链。题库分类、其他私题、独立保存的试卷/教案快照及旧备份不由此操作清除。 |
| `teacher_memory` | 本人偏好 JSON 导出 | 固定确认清除偏好、提议、观察和反馈，关闭自动学习；仍保留版本状态记录，版本号前进。不是完整账户擦除。 |
| `private_library` / `private_library_files` | 本人原文件、文本修订及校对稿 DOCX/PDF | 移入回收站后仍保留原文件、文本和派生记录，可恢复；无全链路永久擦除流程。 |
| `question_capture` / `question_capture_files` | 本人图片及识别/校对版本用于 Solve | 尚无覆盖媒体与识别修订的永久删除流程；清空前端任务不等于删除服务端文件。 |
| `exam_papers` / `exam_paper_assets` | 本人历史与精确版本学生卷/答案卷/细目表导出 | 回收可恢复；不可变版本与资产快照仍保留，尚无全链路永久擦除流程。 |
| `lesson_plans` | 本人 M10 历史及精确版本 DOCX/PDF | 回收可恢复；不可变版本仍保留。旧教案 REST 只允许本地开发。 |
| `pdf_imports` / `pdf_import_files` | 旧批次、原文件与拆题管理 | Beta 中停用；本地回收仍保留文件、候选和事件，不等于永久擦除。 |
| `question_bank` / `question_media` | 当前产品通过受控检索/选题使用；旧管理 REST 在 Beta 停用 | 公共与资料派生题不等于辅助命题私库；本轮未新增按账户清除该存储的能力。 |

补充边界：

- Beta 会话不进入备份。退出使令牌失效，不删除教师内容；失效记录可通过下述维护命令预览后确认清理，没有自动清理计划。
- 生成导出文件、派生相似性索引不进入备份，但这**不代表已从活动存储自动清除**。
- 已创建的备份是独立快照，不会随活动记录删除而自动擦除；备份保留期限、清除流程及恢复时防止已删除内容重新出现的规则尚未验收。
- 不保证 SQLite 删除等同于介质级不可恢复擦除；本轮验证的是活动业务数据不可再通过接口读取。
- 没有后台管理员恢复私题、Agent 永久删除或批量注销入口。

## 会话维护：默认预览，明确确认才清理

所有者已批准“允许增加预览和确认清理”。`BetaSessionMaintenance` 只接受配置中的会话数据库路径；命令不提供教师选择、内容删除、恢复备份或任意数据库参数。使用安装了本项目 API 的 Python 环境，在本仓库执行：

```powershell
# 默认预览：只输出总数、有效、到期、已退出、无法判定记录数及截止时间。
python -m app.modules.beta_access.maintenance_cli
# 等价的显式预览。
python -m app.modules.beta_access.maintenance_cli preview
# 操作者核对预览后，明确确认删除失效登录记录。
python -m app.modules.beta_access.maintenance_cli prune --confirm
```

- 未带 `--confirm` 的 `prune` 在加载配置/打开数据库前拒绝；没有后台定时器，也没有用户界面/Agent Tool 入口。
- 到期时间按带时区时间比较，恰好到期也可清理；到期且撤销的记录只计入撤销一类。有效登录及无法判定的异常记录保留。
- 不创建缺失库。拒绝非普通文件、符号链接、文件及父目录的 Windows reparse point、非会话专库、异常 schema、触发器或外键。
- 清理时重新核对实时记录，不使用旧预览作为删除名单；在同一写事务内枚举精确键、删除、核对数量，任一步失败完整回滚。
- 输出只有计数、截止时间或固定错误码；不输出访问码、令牌/哈希、教师标识、路径或原始异常。配置错误同样脱敏。
- 删除的是已经失效的登录记录，不删除教师内容、导出文件、备份或数据库文件；没有恢复这些会话记录的产品入口。不是磁盘安全擦除，SQLite 空闲页/WAL 不保证抹除。
- 本轮只对临时合成数据库执行确认清理，没有运行真实会话清理。

## HTTP 缓存保护

`/api/v1` 正常响应及经应用处理的错误响应设置 `Cache-Control: private, no-store`；流式响应另保留 `no-transform`。搜题/解题的前端流式转发以及连接失败响应不再使用允许存储后重验证的 `no-cache` 作为唯一保护。测试覆盖会话状态/签发/退出、偏好读取/导出、401/422、Cookie 保留和不缓冲流式内容；新加的 Beta 旧管理入口限制也经过匿名及双用户测试。

这些指令约束遵守协议的 HTTP 缓存，不删除已有下载文件、页面内存状态或之前缓存；框架最外层的未处理异常、外部反向代理生成的错误仍需在部署层单独核对。不是完整浏览器隐私审计。

## 仍阻止 M12 完成的项目

1. 完整 API 路由与派生数据访问面的隔离审查；本轮修复不等于全站鉴权审计完成。
2. 对尚无永久删除流程的存储确定产品语义、删除范围和保留策略，再实现并演练；不得擅自连带删除保存快照或真实文件。
3. 导出临时文件、后台任务、备份的保留及清除策略，恢复时的删除一致性；会话手动清理已接入，自动维护频率尚未确定。
4. M12 全范围固定评测和完整 Gate E/P/Q、回滚点及所有者阶段转换确认。M13 不启动。

## 任务、模型上下文及备份检查补充

- Search/Solve 的任务快照现绑定 current teacher。其他用户猜中 ID 也不能读取、回放、取消或恢复；无 owner 的旧记录不可认领，跨 owner run ID 冲突不能覆盖内容。
- 四类 Agent 入口使用教师/模块作用域签名会话；同一浏览器别名不会把不同教师送入同一个模型上下文。签名过期或篡改在 Runtime 调用前拒绝。当前进程密钥不会落盘，API 重启需清空任务重试，不删除保存内容；不支持多 API worker。
- 路由清单测试检查所有有效 FastAPI 路由（含隐藏内部路由）的身份依赖；固定公共例外和 9 个 M2M Tool。匿名、过期、退出重放、空能力逐路由请求均被拒绝。对象级校验仍由各业务测试和双用户演练保证，不能只以认证依赖存在作为完整权限证明。
- 备份对原始目标/来源/backup/payload 路径先查链接和全部父目录，再解析路径；拒绝 Windows reparse、异常存储标识和 payload 路径穿越。清理失败 staging 前重新检查，不跟随链接递归删除。只验证临时合成目录，不清理真实备份。
- 固定评测命令与完成条件集中在 [M12 Gate 记录](M12-GATE-REVIEW.md)。备份保留、恢复时删除一致性及其他存储永久删除仍等待产品决策；此补充不改变上表删除语义。
