# M12 数据生命周期与删除演练

核对日期：2026-09-05。M12 第五切片已完成；这里记录的是 Closed Beta 的活动数据、独立备份和临时派生物语义，不是账户注销、介质安全擦除或生产容灾承诺。

## 固定删除语义

永久删除只能由当前登录用户发起。资料、试卷和教案必须先进入回收站；所有支持的对象都要求当前版本时间戳和固定确认文字 `永久删除我选择的内容`。浏览器不能选择 owner，Agent、管理员和旧接口没有代删能力。跨用户、匿名、错误确认、活动态和过期版本均失败关闭。

| 对象 | 活动存储删除范围 | 明确保留范围 |
| --- | --- | --- |
| 本人私题 | 题目、来源草稿及修订链 | 独立保存的试卷/教案快照、其他私题与分类 |
| 私人资料 | 资料记录、原文件、OCR、文本修订、拆题候选和生命周期事件 | 已经独立保存的题目、试卷和教案快照 |
| 单题图片 | 当前图片对象、全部媒体修订、识别/校对和 Solve 使用记录 | 已经独立保存的解题或其他业务快照 |
| 历史试卷 | 当前试卷及全部不可变版本、该试卷独占资源目录 | 来源公共题、本人私题和其他试卷 |
| 历史教案 | 当前教案及全部不可变版本 | 来源教材、题目、资料和其他教案 |
| 教师偏好 | 偏好、提议、观察和反馈；关闭自动学习并推进版本 | 最小版本状态记录，不等于账户注销 |

删除协调器先写入 owner/object 精确墓碑，再执行业务存储事务；失败时只回滚本次墓碑。删除账本位于 owner 备份集合之外。恢复演练先验证原始备份，再在隔离目录应用当前墓碑，因此较旧备份不会让已删除对象重新出现。活动删除不会改写或连带删除已经形成的独立备份。

SQLite 删除只保证活动业务接口不可再读取，不保证底层介质立即不可恢复。文件删除拒绝路径逃逸、符号链接和 Windows reparse point；文件锁定或目录异常时业务事务失败关闭。

## 保留与清理

- 备份固定保留 30 天。`retention-preview` 只读列出可清理计数；`retention-prune --confirm` 在删除前重新校验，只删除私有备份根目录下已过期且清单/校验和完整的直接子目录。近期、损坏、无法分类、链接或异常目录一律保留。
- Beta 登录记录不进入备份。`BetaSessionMaintenance.preview/prune` 默认预览；只有明确 `prune --confirm` 才原子删除已到期或已退出的记录。有效和无法判定记录保留，无浏览器、Agent 或自动计划入口。
- DOCX/PDF 导出使用唯一临时文件名，在响应发送完成后立即删除；用户收到的下载文件名保持稳定。原始上传文件不属于临时导出，绝不由该清理器删除。
- 进程内后台任务的成功、失败和取消元数据保留 24 小时后自动移除；运行中任务不清理。服务重启会清空进程内任务状态，但已保存业务内容不受影响。
- 旧导入、旧题库管理/媒体、旧相似度/解题、旧教案、旧组卷写入和全局模型管理接口在 Closed Beta 中于存储/provider 之前停用；本地开发模式保持兼容。
- `/api/v1` 和 Search/Solve 流式代理使用 `private, no-store`；这不等于删除浏览器已下载文件或操作系统缓存。

## 操作者命令

从仓库根目录、已安装 API 开发依赖的环境执行：

```powershell
python -m app.modules.beta_access.maintenance_cli preview
python -m app.modules.beta_access.maintenance_cli prune --confirm
python -m app.modules.beta_recovery.cli retention-preview
python -m app.modules.beta_recovery.cli retention-prune --confirm
```

未确认的清理在加载配置或打开存储前拒绝。命令只接受配置中的会话库/备份根，输出稳定错误码和计数，不输出路径、用户标识、访问秘密、内容或原始异常。

## 验证结果与边界

M12 固定入口为 `python -m pytest -c apps/api/pytest-m12.ini -q`，结果 **199 passed、1 skipped**；完整 API 为 **648 passed、1 skipped**。Teacher Web 102 项、Agent 42 项测试、双方类型检查与生产构建通过。跳过项仅因系统不允许创建真实符号链接；Windows reparse 拒绝有无需权限的确定性测试。

测试仅使用临时目录、项目自建合成内容和 Runtime/OCR/模型替身。没有清理真实登录、真实用户内容或真实备份；测试依赖也已验证不会创建默认运行账本。真实教师指标、生产认证、多 worker 会话持久化、云端密钥管理、RTO/RPO 和介质级擦除属于后续阶段。
