# M9 Paper Agent 固定开发边界

> 状态同步（2026-09-05）：M0–M12 已完成，项目所有者已确认进入 M13，当前进行中。本文的切片过程、测试数量和 Gate 结论保留为当时证据；后续行为与当前边界见 [开发状态](PROJECT-STATUS.md) 和 [开发边界](DEVELOPMENT-BOUNDARY.md)。

更新日期：2026-08-29
状态：已完成；六条切片与完整 Gate 已通过，所有者于 2026-08-30 确认进入 M10。

## 1. 唯一目标

把中国高中数学教师的自然语言组卷要求转换为可编辑的 `PaperBlueprint`，再在教师确认蓝图后，从受控题库与当前 owner 明确选择的私题中形成可编辑试卷草稿、双向细目表和可导出版本。

M9 复用既有 `ExamPaperComposer`、`ExamPaperStudio`、`ExamPaperDocumentRenderer`、QuestionBank、PersonalQuestionLibrary、RightsGate 与 MathVerifier，不复制第二套选题、存储或导出逻辑。

## 2. 分切片交付

1. **蓝图规划**：自然语言 → 可编辑 `PaperBlueprint` 草稿；不查题、不生成题、不保存。
2. **蓝图确认与受控选题**：只有教师确认后才调用组卷业务模块；候选必须通过 owner、权利、验证、重复与相似度门禁。
3. **结构核对与选题分析**：核对题量、分区和配分；选题完成后自动总结实际知识范围与难度。知识/难度偏差只提示，不阻止教师保存。
4. **可编辑试卷与双向细目表**：教师可调整题目、顺序、配分和结构，修改保持可追踪。
5. **显式保存与不可变版本**：教师显式保存后才建立 owner-scoped 版本快照；题量、题型/分区、配分、总分或分析与蓝图有偏差时先提示“试卷尚未完善”并提供取消/确认。教师确认后，服务端重新核对题目 revision、可信/完整状态和草稿指纹，再保存当前精确版本。
6. **已保存版本精确导出**：只从当前 owner 的指定已保存版本生成学生卷、答案卷和双向细目表 DOCX/PDF；屏幕草稿和未保存修改不能混入导出。

每条切片完成只表示 M9 进行中；全部 Gate 通过前不得宣称 Paper Agent 完成，也不得开始 M10。

## 3. 第一切片接口与边界

`PaperBlueprintPlanning.plan(PaperBlueprintBrief) -> PaperBlueprintDraft`

该深模块负责：

- 从一句话中整理年级、用途、考试时间、目标分值、知识范围、难度和题型配额；
- 对未明确字段给出可见的默认假设，而不是静默猜测；
- 返回教师可逐项编辑的蓝图草稿；
- 固定披露后续只可使用通过数学验证且未被拒绝的题目，私题只能由当前 owner 明确选择；
- 固定 `draft / editable / unconfirmed / unsaved`，且副作用为空。

第一切片不得：

- 查询或选择任何题目；
- 自动调用辅助命题；
- 自动保存试卷、私题或蓝图；
- 接收浏览器提交的 owner、rights、verification 或 visibility 结论；
- 把蓝图草稿表述为已生成试卷；
- 提供导出或发布入口；
- 引入大学数学、学生端、账号、支付、Lesson 或 Memory 范围。

## 4. M9 永久门禁

1. 只服务中国普通高中数学；明确大学范围必须拒绝或要求改写，不得把越界内容混入试卷。
2. 只从通过既有数学验证门禁且未被教师拒绝的题目中选题；模型文本不能替代验证事实。
3. 所有题目必须保留来源、rights、revision、verification 和 review 状态。
4. 公共题与私题保持数据和视觉区分。引用私题不复制、不改 owner、不提升 visibility；只有当前 owner 明确选择才可引用。
5. 供给不足时返回真实缺口和可编辑建议；不得为了满足题量自动命题、自动保存或自动加入试卷。
6. 重复题和高相似题必须在进入草稿前受控检查；不能仅靠题目 ID 去重。
7. 蓝图、选题草案与试卷版本是不同状态。教师确认蓝图不等于保存试卷；只有显式保存才建立版本快照。
8. Agent 不直接访问数据库或私人文件；链路仍为 Agent → Tool → FastAPI 业务模块 → 门禁 → storage。
9. M9 的用户验收终点是一份可编辑、来源可追踪、可明确保存、可导出的试卷及双向细目表；结构或配分偏差必须诚实提示，但不能剥夺教师保存当前版本的权利，内部失败也不能被伪装成完成。
10. 教师明确选择并通过题目质量、权利、owner、高中范围、重复与相似度硬门禁的题目，不得再因知识范围、难度、题量、分区、配分或总分与初始蓝图有偏差而被移除或禁止保存；系统应自动总结实际结果，在保存前二次确认偏差。

## 5. 第二切片接口与边界

`PaperBlueprintSelection.select(PaperBlueprintSelectionCommand, owner_id=...) -> PaperBlueprintSelectionDraft`

该深模块统一负责：

- 只接收教师可编辑的蓝图事实，以及明确勾选的公共题/私题 ID；当前教师身份由 FastAPI 注入；
- 公共候选固定经过 `passed + approved + active + public` 门禁，且不得带发布阻断项；
- 私题只能读取当前 owner 明确选择的 active 完整题目，不复制、不改 owner、不提升 visibility；
- 公共题库选择器只列出已经通过公共门禁的现成题，不能由浏览器覆盖 owner、visibility、review、verification 或权利事实；
- 教师明确勾选的题目代表显式意图，不再被蓝图的软知识范围二次过滤；仍必须通过高中范围、题型容量、重复与高相似硬门禁。未明确选择的公共候选继续按蓝图知识范围自动匹配；
- 按蓝图分区与配分建立确定性候选顺序，并保留来源、权利、revision、verification、review 与 owner scope；难度用于未明确选择候选的排序和最终分析，不覆盖教师明确选题；
- 供给不足时返回分区级题量/分值缺口与建议，不用未通过门禁的题目凑数，也不触发辅助命题；
- 固定返回 `selection_draft + editable + confirmed + unsaved`，副作用为空。

第二切片不得：

- 接收浏览器提交的 owner、rights、verification、review、visibility 或保存结论；
- 查询或采用其他 owner 未明确授权的私题；
- 把教师确认蓝图解释为保存试卷、建立版本或允许导出；
- 为填满蓝图自动命题、自动复制私题或降低验证/审核门槛；
- 隐藏题库真实缺口，或把候选清单表述为完整正式试卷。

## 6. 第三切片接口与边界

`PaperBlueprintCoverage.audit(blueprint=..., items=...) -> PaperBlueprintCoverageAudit`

该深模块负责：

- 逐分区核对目标/实际题量与配分；
- 逐项核对确认蓝图中的知识范围是否真实出现在候选题；
- 使用 `ExamPaperComposer` 的同一难度分布规则，核对 1–5 级目标题量、实际题量、实际分值和平均难度偏差；
- 把实际知识范围和难度作为选题后的自动分析返回并写入双向细目表；与初始蓝图有偏差时只提示，不改变教师选择，也不阻止正式保存；
- 题目供给不足时明确返回 `insufficient_supply`，不把不完整候选冒充难度达标；
- 固定只读、无副作用，检查结果随 `selection_draft` 返回但不建立试卷、版本或保存记录。

第三切片不得：

- 接收浏览器提交的覆盖、难度或通过结论；
- 为修补覆盖/难度偏差自动命题、降低门禁或写入题库；
- 把知识点字符串命中、排版成功或平均难度接近冒充数学验证；
- 把对照结果表述为正式试卷已经完成。

## 7. 第四切片接口与边界

`PaperEditableDrafting.build(command, owner_id=...) -> PaperEditableDraft`

该深模块负责：

- 根据原始蓝图与明确私题 ID 在服务器重新执行受控选题，不接收浏览器回传的来源、owner、rights、verification、review 或 visibility；
- 接受完整题目布局中的 `question_id + position + section_id + score`；历史版本编辑允许加入公共题库或当前 owner 私题中的明确候选，但每个新增 ID 必须在服务端重新通过公共/owner、权利、完整性、验证、高中范围和相似度门禁；仍拒绝遗漏、重复、非法分区和题型错配；
- 允许教师调整题序、同题型分区和配分，并返回相对原候选清单的可读修改记录；
- 每次调整后重新核对分区题量和配分，重新归纳实际知识范围和难度，并同时生成题目→教学维度与教学维度→题目的双向细目表；
- 固定返回 `editable_paper_draft + unsaved + no version + no export`，不写数据库、不复制私题、不改变来源与权限。

第四切片不得：

- 接受浏览器提交的可信结论、owner、保存、版本或导出状态；
- 用编辑接口新增任意题目、绕过受控选题或把缺题草稿冒充完整试卷；
- 为满足总分、知识范围或难度自动命题、降低门禁或改变私题 owner/visibility；
- 把本次内存修改记录冒充已持久化 revision；正式版本只能进入第五切片，导出只能进入第六切片。

## 8. 第五切片接口与边界

`PaperVersioning.save(PaperVersionSaveCommand, owner_id=...) -> PaperSavedVersion`

该深模块负责：

- 接收教师当前可见的蓝图、明确选择的私题 ID、完整布局编辑事实和服务器生成的 `draft_fingerprint`；owner 只能由 FastAPI 当前教师上下文注入；
- 在保存前重新执行受控选题与可编辑草稿构建，不信任浏览器回传的来源、revision、verification、review、rights、owner、版本号或保存结论；
- 重新解析公共题和当前 owner 私题的精确当前 revision，确认题干、选择题选项、最终答案和解析完整，且可信状态没有在编辑期间变化；
- 对照服务器重建结果检查草稿指纹，并重新计算分区题量、题型、配分、总分、知识范围与难度；这些蓝图偏差写入提示与细目表但不阻止教师二次确认后的保存。过期指纹、无任何可用题目或题目可信/内容不完整必须拒绝且不得产生版本副作用；
- 只有教师显式保存动作通过全部检查后，才调用既有 `ExamPaperStudio` 建立 append-only、owner-scoped、包含完整双向细目表的不可变版本快照；
- 返回由服务器确定的 `paper_id + version + owner scope + saved_at + 六种可用导出选项`，但不在保存接口中隐式下载文件。

第五切片不得：

- 接受 Agent、模型或浏览器指定 owner、版本号、可信结论、保存状态或题目快照；
- 把蓝图确认、候选完整、编辑完成或页面按钮状态解释为已保存；
- 对过期 revision、无任何题目、缺选项、未明确标注的缺答案/解析或可信状态变化的草稿建立版本；owner 主动停止并保留的已审核题面是显式例外，按 [开发边界](DEVELOPMENT-BOUNDARY.md) 标注缺少解析并显示“无”；不得仅因题量、题型/分区、配分、总分、知识范围、难度或供给偏差拒绝教师确认保存当前已有题目；
- 复制私题、改变私题 owner/visibility，或把保存试卷解释为保存/发布题目；
- 让一次失败保存留下空版本、半成品版本或版本号跳变。

## 9. 第六切片接口与边界

`PaperSavedExporting.export(paper_id=..., version=..., owner_id=..., kind=..., format=...) -> RenderedExamPaper`

历史组卷直接复用这些 owner-scoped 不可变版本：当前教师只能列出、读取和导出自己的版本，可将自己的记录移入回收站并恢复；也可打开当前版本，调整名称、时长、题目顺序、分区和分值、删减题目，或从服务端重新通过门禁的公共题库/当前 owner 私题中加入题目，再建立同一试卷的新版本。新增题目不能由浏览器直接注入，保存时由服务器重算总分和双向细目表，旧版本继续不可变保留。列表、生命周期动作、读取和修订接口均从服务器 current-teacher context 取 owner，跨 owner 的编号即使被猜中也按不存在处理。

该深模块负责：

- 只读取当前 owner 的精确 `paper_id + version` 不可变快照；跨 owner、未知版本和未保存草稿统一不可见或不可导出；
- 要求版本内同时存在完整题目快照和双向细目表，导出时不重新选题、不读取页面当前编辑状态、不漂移到题库最新 revision；
- 复用 `ExamPaperDocumentRenderer` 生成学生卷、答案卷和双向细目表三类文档的 DOCX/PDF，共六种受控导出；
- 学生卷不泄露答案和解析；答案卷包含可读最终答案与完整解析；双向细目表同时包含题目→教学维度和教学维度→题目；
- 文件名、内容类型和下载内容由服务端决定，导出不改变版本、题目、私题或可信状态。

第六切片不得：

- 从未保存草稿、浏览器回传内容或“最新版本”模糊指针导出；
- 允许浏览器通过 owner、visibility、verification 或 revision 参数改变导出内容；
- 在导出阶段补题、改题、重算答案、自动保存或升级可信状态；
- 把排版成功冒充数学验证或教师审核通过。

## 10. 当前切片验收

- 三条典型高中组卷描述能得到结构化且总分守恒的蓝图；
- 缺少年级、时间、总分或范围时，默认假设在结果中可见并可修改；
- 明确大学范围被业务模块拒绝；
- 每个蓝图固定声明未确认、未保存、未选题、未生成题目；
- Teacher Web 可编辑标题、年级、时长、总分、难度、范围和各题型数量/配分；
- 页面切换不会产生业务写入；
- FastAPI、Teacher Web 专项测试、类型检查与生产构建通过。
- 蓝图确认前不执行选题，确认请求只包含可编辑蓝图事实和私题 ID；
- 公共题、当前 owner 私题、跨 owner 私题、未通过门禁题和重复/高相似题均有自动化边界测试；
- Teacher Web 能明确勾选自己的私题，并在候选结果中区分公共/私题、展示选项、配分、来源与可信事实；
- 供给不足以分区级真实缺口呈现，候选草案仍保持未保存且不出现自动命题、保存或导出入口。
- 分区题量/配分、逐项知识范围和 1–5 级难度目标均有确定性对照；任何蓝图偏差都会形成可见提示但不禁用保存，保存前必须出现取消/确认二次选择。
- Teacher Web 以可读中文展示覆盖与难度对照，不泄露内部 owner、verification、revision 或权限字段；320/375/414/768px 无横向溢出。
- 可编辑试卷的初始结果与每次调整都重新通过服务器受控选题 seam；浏览器只提交蓝图、明确私题 ID 和题目布局编辑事实。
- 题序、分区和配分调整可追踪；页面状态按当前编辑值实时核对，缺题、题型/分区或总分不一致不会被冒充为结构完成，也不会被误作不可保存。
- 双向细目表同时提供题目→分区/题型/章节/知识点/难度/分值和教学维度→对应题号/题量/分值。
- 编辑阶段仍固定未保存、未建立版本、不可导出；只有显式保存按钮才能提交第五切片。
- 保存时服务器重新解析精确题目 revision、重建草稿并检查指纹；过期草稿返回冲突且不产生版本，跨 owner 和浏览器伪造 owner/version/trust 均 fail closed。
- 每次成功保存只建立一个不可变版本；页面修改后必须再次显式保存，旧版本内容不随题库或页面变化漂移。
- 当前 owner 可对精确已保存版本导出学生卷、答案卷和双向细目表的 DOCX/PDF；学生卷不含答案，答案卷含可读解析，双向细目表包含正向与反向规格。
- 真实 Teacher Web 已完成“编辑 → 显式保存版本 → 六种导出入口”验收；学生卷、答案卷和双向细目表 PDF 均完成逐页视觉检查，无裁切、重叠、乱码或公式不可读。
