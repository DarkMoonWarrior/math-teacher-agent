# M9 Paper Agent 固定开发边界

更新日期：2026-08-28
状态：进行中；本文件是 M9 的范围与验收依据。

## 1. 唯一目标

把中国高中数学教师的自然语言组卷要求转换为可编辑的 `PaperBlueprint`，再在教师确认蓝图后，从受控题库与当前 owner 明确选择的私题中形成可编辑试卷草稿、双向细目表和可导出版本。

M9 复用既有 `ExamPaperComposer`、`ExamPaperStudio`、`ExamPaperDocumentRenderer`、QuestionBank、PersonalQuestionLibrary、RightsGate 与 MathVerifier，不复制第二套选题、存储或导出逻辑。

## 2. 分切片交付

1. **蓝图规划**：自然语言 → 可编辑 `PaperBlueprint` 草稿；不查题、不生成题、不保存。
2. **蓝图确认与受控选题**：只有教师确认后才调用组卷业务模块；候选必须通过 owner、权利、验证、重复与相似度门禁。
3. **覆盖与难度检查**：将实际题目与蓝图对照，缺口明确呈现，不为凑题自动命题。
4. **可编辑试卷与双向细目表**：教师可调整题目、顺序、配分和结构，修改保持可追踪。
5. **显式保存与导出闭环**：教师显式保存后才建立版本快照；学生卷、答案卷和双向细目表导出完整可用。

每条切片完成只表示 M9 进行中；全部 Gate 通过前不得宣称 Paper Agent 完成，也不得开始 M10。

## 3. 第一切片接口与边界

`PaperBlueprintPlanning.plan(PaperBlueprintBrief) -> PaperBlueprintDraft`

该深模块负责：

- 从一句话中整理年级、用途、考试时间、目标分值、知识范围、难度和题型配额；
- 对未明确字段给出可见的默认假设，而不是静默猜测；
- 返回教师可逐项编辑的蓝图草稿；
- 固定披露后续只可使用通过数学验证且未被拒绝的题目，私题只能由当前 owner 明确选择；
- 固定 `draft / editable / unconfirmed / unsaved`，且副作用为空。

第一切片不得：

- 查询或选择任何题目；
- 自动调用辅助命题；
- 自动保存试卷、私题或蓝图；
- 接收浏览器提交的 owner、rights、verification 或 visibility 结论；
- 把蓝图草稿表述为已生成试卷；
- 提供导出或发布入口；
- 引入大学数学、学生端、账号、支付、Lesson 或 Memory 范围。

## 4. M9 永久门禁

1. 只服务中国普通高中数学；明确大学范围必须拒绝或要求改写，不得把越界内容混入试卷。
2. 只从通过既有数学验证门禁且未被教师拒绝的题目中选题；模型文本不能替代验证事实。
3. 所有题目必须保留来源、rights、revision、verification 和 review 状态。
4. 公共题与私题保持数据和视觉区分。引用私题不复制、不改 owner、不提升 visibility；只有当前 owner 明确选择才可引用。
5. 供给不足时返回真实缺口和可编辑建议；不得为了满足题量自动命题、自动保存或自动加入试卷。
6. 重复题和高相似题必须在进入草稿前受控检查；不能仅靠题目 ID 去重。
7. 蓝图、选题草案与试卷版本是不同状态。教师确认蓝图不等于保存试卷；只有显式保存才建立版本快照。
8. Agent 不直接访问数据库或私人文件；链路仍为 Agent → Tool → FastAPI 业务模块 → 门禁 → storage。
9. M9 的用户验收终点是一份可编辑、来源可追踪、结构与配分一致、可导出的完整试卷及双向细目表；内部失败不能被伪装成完成。

## 5. 第二切片接口与边界

`PaperBlueprintSelection.select(PaperBlueprintSelectionCommand, owner_id=...) -> PaperBlueprintSelectionDraft`

该深模块统一负责：

- 只接收教师可编辑的蓝图事实和明确勾选的私题 ID；当前教师身份由 FastAPI 注入；
- 公共候选固定经过 `passed + approved + active + public` 门禁，且不得带发布阻断项；
- 私题只能读取当前 owner 明确选择的 active 完整题目，不复制、不改 owner、不提升 visibility；
- 进入候选草案前执行题型、知识范围、高中范围、重复与高相似检查；
- 按蓝图分区、难度与配分建立确定性候选顺序，并保留来源、权利、revision、verification、review 与 owner scope；
- 供给不足时返回分区级题量/分值缺口与建议，不用未通过门禁的题目凑数，也不触发辅助命题；
- 固定返回 `selection_draft + editable + confirmed + unsaved`，副作用为空。

第二切片不得：

- 接收浏览器提交的 owner、rights、verification、review、visibility 或保存结论；
- 查询或采用其他 owner 未明确授权的私题；
- 把教师确认蓝图解释为保存试卷、建立版本或允许导出；
- 为填满蓝图自动命题、自动复制私题或降低验证/审核门槛；
- 隐藏题库真实缺口，或把候选清单表述为完整正式试卷。

## 6. 当前切片验收

- 三条典型高中组卷描述能得到结构化且总分守恒的蓝图；
- 缺少年级、时间、总分或范围时，默认假设在结果中可见并可修改；
- 明确大学范围被业务模块拒绝；
- 每个蓝图固定声明未确认、未保存、未选题、未生成题目；
- Teacher Web 可编辑标题、年级、时长、总分、难度、范围和各题型数量/配分；
- 页面切换不会产生业务写入；
- FastAPI、Teacher Web 专项测试、类型检查与生产构建通过。
- 蓝图确认前不执行选题，确认请求只包含可编辑蓝图事实和私题 ID；
- 公共题、当前 owner 私题、跨 owner 私题、未通过门禁题和重复/高相似题均有自动化边界测试；
- Teacher Web 能明确勾选自己的私题，并在候选结果中区分公共/私题、展示选项、配分、来源与可信事实；
- 供给不足以分区级真实缺口呈现，候选草案仍保持未保存且不出现自动命题、保存或导出入口。
