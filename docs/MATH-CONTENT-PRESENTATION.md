# 数学内容可读展示规范

更新日期：2026-08-22
状态：当前跨阶段展示边界；Solve、私有辅助命题、资料库整理稿、Paper 与 Lesson 均已复用（2026-09-04 同步）

## 1. 目标

教师看到的题面、解题步骤和最终答案必须是排版后的数学内容，不能把 `\frac`、`\sum`、`^`、`_` 等 LaTeX 源码直接当普通正文展示。本规范只约束显示方式，不判断解法属于高中还是大学内容，也不改变 MathVerifier、权利或审核状态。

## 2. 规范输出

- 中文说明放在数学分隔符之外；
- 行内公式使用单个 `$...$`；
- 需要单独成行的公式使用 `$$...$$`；
- 公式使用 KaTeX 兼容 LaTeX，不使用 Markdown 代码块包装；
- Solution 与 Question Authoring provider 必须共用同一数学输出约定，提示版本分别可追踪；命题当前为 `question-authoring-v13-background-closed-loop`。

这一约定继续保留现有 `steps: string[]` 与 `final_answer: string` 业务契约，避免为了展示问题改动可信状态和 Agent Tool 接口。长解析由命题 provider 分段生成和组装，但每段中的中文与公式仍遵守同一约定。

## 3. 渲染与兼容

Teacher Web 的唯一数学展示组件负责：

1. 识别 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]`；
2. 使用 `trust=false` 的 KaTeX 输出 HTML 与 MathML；
3. 对历史题库或旧运行结果中未加分隔符的常见 LaTeX/数学表达做只读兼容识别；
4. 渲染失败时保留可见原文，不静默显示空白；
5. 独立公式只在自身区域横向滚动，不造成整页横向溢出；
6. 中文正文使用正常正文色，强调色只用于步骤编号、警告和可信状态。

兼容识别不是新的内容来源，也不会回写题库、OCR revision 或模型结果。

## 4. 完成 Gate

- 分式、根式、上下标、求和、极限、积分及中文公式混排可读；
- 显式行内公式、独立公式和旧式未分隔公式均有确定性测试；
- KaTeX 失败有可见降级内容；
- 320—1920px 不因公式造成页面级横向溢出；
- Search 说明、Solve 题面/步骤/答案、命题草稿和已保存私题、资料库整理稿及 Paper/Lesson 复用同一底层数学渲染组件；
- M8 选择题的题干与选项分别传入展示组件：题干中不得混入字面 `\\nA.`—`\\nD.`，全部选项在题干后按独立行渲染，公式继续使用同一数学组件；
- 前后端测试、类型检查和生产构建通过。

## 5. 明确不在本修复范围

- 不判断某种解法是否超出高中课程；
- 不改变模型给出的数学结论或推导；
- 不把排版成功冒充数学验证通过；
- 不新增题库、公开发布、private/public、权限或商业规则。
